# website/assets/models/scout.glb

An **original, stylised low-poly stand-in** for the FrodoBots Earth Rover Mini+ ("scout"), built from
geometric primitives (`trimesh` boxes/cylinders/spheres) in the dashboard's colour palette. It is **not derived
from any FrodoBots CAD, photo or mesh** and does not aim to be dimensionally accurate.

License: MIT, same as this repository (© Cagatay Cali).

Why a stand-in: the official Earth Rover Mini+ STEP files live at
<https://github.com/frodobots-org/earth-rover-mini/tree/main/3DPrint> (`body.stp`, `front_top.stp`, `back_top.stp`,
`back_cover.stp`, `camera.stp`, `mini_cover.stp`) but that repository carries **no license**, so we link to them
instead of redistributing or converting them. See the site's *Hardware & 3D files* page.
